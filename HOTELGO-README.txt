HOTELGO for LavaLust - files to copy
====================================
1. Open the folder where you installed LavaLust (example: C:\laragon\www\hotelgo).
2. Copy EVERYTHING inside this "hotelgo-files" folder into it.
   When Windows asks, choose "Replace the files in the destination".
3. Follow the guide (HOTELGO_Step_by_Step_Guide.pdf) from Part 2, Step 3.

NEVER upload your real ".env" file to GitHub. Only ".env.example" is safe to upload.
